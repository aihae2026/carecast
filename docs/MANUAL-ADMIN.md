> 이 설명서는 **이미 돌아가고 있는 CareCast를 관리하시는 분**을 위한 것입니다.
> 방송 시각을 바꾸고, 안 나간 방송을 확인하고, 고장났을 때 되살리는 일입니다.
> 프로그램을 고칠 줄 아실 필요는 없습니다.
>
> **기준**: 2026-09-15 화면. 화면이 바뀌면 이 문서도 같이 고칩니다.

**설명서가 셋입니다. 겹치지 않게 나눠 두었습니다.**

| 문서 | 누구를 위한 것 |

| **이 문서** | **시스템을 맡으신 담당자.** 시각·문안 바꾸기, 점검, 고장 대응 |

## 0. 가장 먼저 — 이 시스템의 생김새

```
시설 PC 1대
 ├─ 방송 프로그램(node.exe) ── 시각을 재고, 문안을 만들고, 소리를 냅니다
 ├─ database.db ───────────── 예약·이력·설정·API 키가 전부 이 파일 하나에
 └─ 방송 화면(Edge 창) ────── 예약 방송의 소리를 내는 창
같은 망의 다른 기기 ── 브라우저로 접속(보고 조작은 되지만 소리는 안 남)
```

**꼭 기억하실 것 셋입니다.**

**① 소리가 나는 곳이 둘입니다.**
「지금 방송」·마이크는 **PC 스피커**에서 나가고, 예약된 안내·음원·배경음악·영상은
**방송 화면(Edge 창)** 에서 나갑니다. 그래서 **그 창이 닫혀 있으면 예약 방송이 무음**이 됩니다.
프로그램은 멀쩡히 돌고 있고 이력에도 성공으로 남을 수 있습니다.

**② 모든 것이 파일 하나에 있습니다.** `server\db\database.db`.
예약도, 방송 시각도, 문안도, API 키도 전부입니다. **이 파일은 git에 없습니다** —
PC를 바꾸면 따라오지 않습니다. 백업이 유일한 되돌아갈 길입니다([BACKUP.md](BACKUP.md)).

**③ 이 PC가 현장 PC인지 시스템이 스스로 압니다.** 판정은 git 브랜치가 하고
(`main`이면 현장), 관리자 화면에서 덮어쓸 수 있습니다. 이 판정에 따라
**자동 업데이트**와 **PC 자동 종료**가 걸리거나 안 걸립니다. 단 자동 업데이트는 현장 PC 라도
**기본으로 꺼져 있고**, `server/.env` 에 `AUTO_UPDATE_ENABLED=1` 을 적어야 켜집니다(끄려면 `=0` — README 「업데이트」).

## 1. 관리자 화면 지도

주소는 `http://localhost:3001/admin` 입니다(다른 기기에서는 `localhost` 대신 그 PC의 IP).

**머리줄 탭이 다섯입니다** — 「간편」·「캘린더」·「자동순서」·「업로드」·「설정」.

| 탭 | 무엇 |
|---|---|
| **간편** | 평소 쓰는 화면. 방송을 내보내고 오늘 일과를 봅니다 |
| **캘린더** | 달력·예약 관리 |
| **자동순서** | 일과방송 5종의 **시각과 문안과 순서** |
| **업로드** | 음원·동영상 올리기 |
| **설정** | 아래 사이드바 화면들 |

> **휴대폰에서는 「간편」·「캘린더」 둘만 보입니다.** 다섯을 다 넣으면 좁은 화면에서
> 머리줄이 두 줄이 되기 때문입니다. 나머지 셋은 **오른쪽 손잡이를 눌러 서랍**을 열면
> 맨 아래 **「관리」 줄**에 있습니다 — 「전체 예약 관리」·「자동 순서」·「업로드」·「설정」.
>
> 서랍은 PC에서도 열리니, 그 길로 가셔도 같은 화면입니다.

**사이드바** — 세 갈래입니다.

| 갈래 | 화면 | 무엇 |
|---|---|---|
| **모니터링** | 대시보드 | 지금 상태, 최근 방송 로그, 기능 켬/끔 |
| | 방송 로그 | 지난 방송 전체 이력 |
| **방송설정** | 음량 및 TTS | 소리 크기, 목소리 |
| | 즐겨찾기 버튼 | 첫 화면에 둘 자주 쓰는 방송 문구 |
| **시스템운영** | 초기 설정 | 처음 세팅용 마법사 |
| | 시스템 설정 | 홀 TV 문구, PC 자동 종료, 기상특보 자동방송, 「지금 업데이트」(손으로 받기 — 자동 업데이트를 켜고 끄는 칸은 없고 `.env` 로 정합니다) |
| | AI · API 연동 | 날씨·AI 키를 넣는 곳 |
| | 비상 방송 관리 | 비상 상황 문구 |
| | 개발 일지 | 무엇을 언제 고쳤는지 |

> **「사용자 권한 관리」는 없습니다.** 준비 중이 아니라 **일부러 안 만들었습니다.**
> 방송을 내보내야 하는 순간에 로그인을 요구하면 그게 사고라서, 시설 내부망 안에서는
> 누구나 바로 조작할 수 있게 두었습니다.
> **다만 이 망에 외부인이 들어올 수 있게 되면**(게스트 와이파이 개방·원격 접속 허용)
> 이 전제는 다시 보셔야 합니다.

## 2. 일과방송 바꾸기 — 시각·문안·순서

머리줄 **「자동순서」** 입니다(휴대폰에서는 서랍 「관리」 → **「자동 순서」**).
방송 다섯 종이 각각 카드 하나입니다.

- **방송 시간** — 저장 방법이 카드 종류에 따라 다릅니다.
  - **고정 일과방송**(아침·점심·저녁 마무리 등 처음부터 있는 카드): 시각을 고친 뒤 화면 아래 **「설정 저장」** 을 눌러야 저장됩니다. 누르지 않고 다른 화면으로 가면 바뀐 시각이 사라집니다.
  - **사용자 정의 방송**(「새 자동순서」로 직접 만든 카드): 시각을 고치고 칸 밖을 클릭하면 바로 저장됩니다.
- **자동 방송** 토글 — 꺼져 있으면 시각이 되어도 안 나갑니다.
- 아래가 **단계 목록**입니다. 차임 → 안내 음성 → 음원 → 배경음악 순서를 여기서 짭니다.

> **새로 만든 자동순서는 일부러 꺼진 채로 만들어집니다.** 시각을 정하고 켜셔야 나갑니다.
> 꺼진 토글은 고장이 아닙니다.

**시각을 바꾸실 때 반드시 확인하실 것**

- 점심·저녁 방송 시각은 **어르신들이 식사 전에 부르시는 동요가 끝나는 자리**에 맞춰 둔
  값입니다. 그냥 둥근 숫자로 옮기면 **동요와 방송이 겹칩니다.**
- 방송끼리 시간이 겹치지 않는지 보십시오. 앞 방송이 6분 가까이 가는 것도 있습니다
  (기도·묵상 단계를 켠 저녁 마무리, 아침 투약 안내).

**문안을 바꾸실 때**

- 문안은 저장하면 **다음 방송부터** 그대로 나갑니다. 미리 들어 보실 수 없습니다 —
  들으시려면 그 방송을 「지금 실행」으로 한 번 내보내 보셔야 하는데, **그러면 어르신들께
  실제로 들립니다.** 근무 시간대를 피하십시오.
- 어르신 실명은 넣지 않으시는 편이 낫습니다. 이유는 §7에 적었습니다.

## 3. 예약 관리

서랍 「관리」 → **「전체 예약 관리」** 를 누르면 캘린더가 **목록 보기**로 열립니다.
머리줄 **「캘린더」** 탭은 달력 모양으로 엽니다 — 같은 화면의 두 가지 보기입니다.

- **반복 예약** — 매일·평일·특정 요일. 환기 안내가 이것입니다.
- **1회 예약** — 그날 한 번. 지나가면 자동으로 정리됩니다.
- **짝이 있는 예약** — 환기방송처럼 「1차」·「2차」로 갈라지는 것은 **한 묶음**입니다.
  하나만 지우면 반쪽이 남습니다.
- **지나간 날짜에는 예약을 넣을 수 없습니다.** 넣어도 안 울리기 때문입니다.

> **AI가 만든 예약은 사람이 확정해야 들어갑니다.** 말하듯 적어 만든 초안은 별도 표에
> 있고, 「예약 확정」을 누르기 전에는 방송될 방법이 없습니다. 이건 설계입니다.

## 4. 음원·동영상 올리기

머리줄 **「업로드」** 입니다(휴대폰에서는 서랍 「관리」 → **「업로드」**).

- 올린 음원은 자동순서의 단계나 예약에서 고를 수 있습니다.
- **파일 이름에 한글을 쓰셔도 됩니다.** 깨져 보이면 그건 알려진 문제였고 고쳐졌습니다.
  그래도 깨져 보이면 담당자에게 알려 주십시오.
- **업로드하면 받아쓰기 초안이 자동으로 만들어집니다**(자막용). 초안일 뿐이라
  그대로 쓰이지 않고, 사람이 고쳐야 반영됩니다.

## 5. 소리

사이드바 **「음량 및 TTS」** 입니다. 채널이 여섯입니다.

| 채널 | 무엇 |
|---|---|
| 전체 소리 | **PC 자체 음량**입니다. 이것만 성격이 다릅니다 — 아래 주의 |
| 안내 음성 | 방송 목소리 |
| 음원 | 올린 mp3 |
| 배경음악 | 올린 배경음악 파일 |
| 영상 | 올린 동영상 |
| TV 송출 | 홀 TV로 나가는 소리 |

> **「전체 소리」를 끄시면 방송이 통째로 안 들립니다.** 이것만 PC 설정이라 **끈 값이
> 그대로 저장되고**, 새로고침해도 돌아오지 않습니다. 점검 중에 내리셨으면
> **반드시 다시 올려 주십시오.** 나머지 슬라이더는 이 시스템 안에서만 도는 값입니다.

**우선순위가 셋입니다** — 아래로 갈수록 약합니다.

1. 그 방송에만 실린 값
2. 그 예약 행에 저장된 값 (예약 편집에서 「이 방송만」)
3. 위 화면의 시스템 기본값

「이번 방송만 잔잔하게」는 **2번에 넣습니다.** 3번을 바꿨다가 되돌리는 방식은 쓰지 않습니다 —
되돌리기 전에 프로그램이 꺼지면 그 값이 그대로 남기 때문입니다.

## 6. API 키 — 여기서 가장 많이 헤맵니다

사이드바 **「AI · API 연동」** 입니다.

**키는 서비스마다 다릅니다. 하나를 여러 칸에 복사해 넣으면 전부 401로 죽습니다.**
실제로 그렇게 넣어 두어서 날씨·자외선·미세먼지가 통째로 안 나온 적이 있습니다.

| 칸 | 어느 서비스에서 받나 |
|---|---|
| 단기예보 | data.go.kr |
| 기상특보 | data.go.kr (비워 두면 단기예보 키를 씁니다) |
| **기상청 API허브** | **apihub.kma.go.kr — 위와 완전히 다른 곳입니다** |
| 자외선 | data.go.kr (생활기상지수) |
| 미세먼지 | 에어코리아 |
| Gemini | Google AI Studio |

**「유효한 인증키가 아닙니다」가 뜨면** — 키가 틀린 게 아니라 **다른 서비스의 키**일 수
있습니다. 넷의 **길이를 비교해 보십시오.** 전부 같은 길이면 한 키를 복사해 넣으신 것입니다.

> **키는 이 PC의 database.db 안에만 저장됩니다.** 인터넷에 올라가지 않습니다.
> 다른 PC로 옮기실 때 키는 **따라가지 않습니다** — 새로 넣으셔야 합니다.

### 6-1. 시설 위치 — **키보다 먼저 넣으셔야 할 수도 있습니다**

같은 화면 아래쪽에 **위도·경도** 칸이 있습니다. 처음 설치 마법사의 「연결」 장에서도 묻습니다.

**안 넣으면 기본값(서울) 날씨가 나갑니다.** 오류도 경고도 안 뜹니다 — 화면은 멀쩡한데
방송만 다른 동네 날씨를 읽습니다. 그래서 **가장 찾기 어려운 종류의 어긋남**입니다.

- **지도 앱에서 시설을 길게 누르면** 위도·경도가 나옵니다. 그 두 숫자를 넣으시면 됩니다.
- **처음 설치 마법사**의 「연결」 장에는 **「지금 위치로 넣기」** 버튼이 있어, 브라우저가
  물어본 뒤 자동으로 채워 줍니다. 이 관리자 화면에는 그 버튼이 없습니다 — 손으로 넣습니다.
- 저장하면 **기상청 격자와 가까운 자외선 관측소를 함께 다시 계산**합니다. 격자 번호를
  따로 찾으실 필요가 없습니다.
- 자외선 관측소는 **네 곳(서울·수원·강릉·부산)뿐**이라, 먼 지역이면 *"약 ○○km 떨어져 있어
  자외선 값은 이 시설과 다를 수 있습니다"* 라고 알려 드립니다. 그 말이 뜨면 자외선 안내는
  참고로만 보십시오.
- 위도는 ±90, 경도는 ±180 을 넘으면 저장이 막힙니다. **두 칸을 바꿔 넣으면**(위도 칸에 127
  같은 값) 그 자리에서 걸립니다.

> 키가 하나도 없어도 날씨는 나갑니다(키 없이 쓰는 무료 경로로 넘어갑니다).
> **그때 쓰는 좌표가 바로 이 값입니다.** 그래서 키보다 이게 먼저일 수 있습니다.

## 7. AI에 무엇이 나가는지 — 아시고 쓰셔야 합니다

**말하듯 적은 예약 문장과 AI로 다듬는 문구는 Google 서버로 나갑니다.**

무료로 쓰고 있어서, 보낸 내용이 **Google의 모델 개선에 쓰이고 사람이 읽을 수 있습니다.**
유료로 바꾸면 달라지지만 지금은 그렇습니다.

**보내기 전에 이름은 「사람1」처럼 바꾸고 번호(주민등록번호·휴대폰번호 등)는 지웁니다.** 다만
이름은 「김○○ 어르신」처럼 **호칭이 붙어야 찾습니다** — 호칭 없이 이름만 적으면 그대로 나갈 수 있습니다.

**그래서 관리자께 부탁드리는 것 하나** — 어르신 성함이 들어가는 안내(생신 축하 같은 것)는
**검색창에 말하듯 적지 마시고**, 예약을 직접 만들어 문안 칸에 적어 주십시오.
그 길은 AI를 지나지 않습니다.

### 7-1. 구글 캘린더에 적으신 일정도 **아침 방송으로 나갑니다**

구글 캘린더를 연결해 두시면, 아침 종합 방송이 **오늘 일정 제목을 그대로 읽습니다.**
07시 50분에 **자동으로** 나가는 방송이라 그때 확인창이 뜨지 않습니다.

**그래서 시스템이 알아서 가립니다**(2026년 9월 15일부터).

| 캘린더에 이렇게 적혀 있으면 | 방송으로는 이렇게 나갑니다 |
|---|---|
| 김영희 어르신 생신 | **「김 어르신 생신」** — 성만 남깁니다 |
| 박영수 보호자 면회 010-1234-5678 | **그 일정은 통째로 안 읽습니다** |
| 최영수 어르신 생신 1940년 3월 2일 | **그 일정은 통째로 안 읽습니다** (생년월일) |
| 10시 음악치료 | 그대로 「10시 음악치료」 |

**화면과 캘린더에는 적으신 그대로 남습니다.** 가리는 것은 **스피커로 나가는 말 한 줄**
뿐입니다 — 선생님들은 누구인지 아셔야 하니까요.

**뺀 것이 있으면 알려 드립니다.** 관리자 화면에 *"오늘 캘린더 일정에 개인정보가
있었습니다"* 라고 뜹니다. 그 알림이 보이면 **캘린더 제목에서 번호를 빼 주십시오** —
빼기 전까지는 그 일정이 방송에서 계속 빠집니다.

**주민등록번호·전화번호·생년월일은 캘린더 제목에 적지 마십시오.** 방송에서 빠질 뿐
아니라, 캘린더는 구글 서버에 저장되는 곳입니다.

## 8. 무엇이 나가고 안 나갔는지 보기

**대시보드** 아래 **「최근 방송 로그」**, 전부 보시려면 **「방송 로그」** 입니다.

**경보가 두 종류이고 뜻이 다릅니다.**

| 문구 | 뜻 | 기본 유예 |
|---|---|---|
| **안 나감** | 시작 기록조차 없습니다 | 5분 |
| **안 끝남** | 시작은 했는데 끝났다는 기록이 없습니다 | 60분 |

「안 끝남」은 대개 긴 방송입니다. 음원 단계를 켠 저녁 마무리가 6분 가까이 가서, 예전에 유예가 5분 하나뿐이던
때는 **매일 누락으로 찍혔습니다.** 그래서 둘로 갈랐습니다.

> **「시스템이 성공으로 적었다」는 「소리가 났다」가 아닙니다.**
> 2026년 9월에 기록은 성공인데 실제로는 안 들린 일이 있었습니다.
> 그 뒤로 감지 장치를 더 넣었지만, **여전히 100%는 아닙니다.**
> 이력은 참고로 보시고, 이상하다는 말씀이 나오면 직접 들어 봐 주십시오.

## 9. 소리가 안 난다는 신고를 받으시면

**순서대로 보십시오. 위에서부터가 훨씬 흔합니다.**

시설 PC 브라우저에서 이 주소를 엽니다 — **①~③을 이 한 화면에서 봅니다.**

```
http://localhost:3001/api/health
```

**① `localClients` 가 0입니까** — 가장 흔합니다.
**방송 화면이 하나도 없는 것**입니다. 설치본은 바탕화면의 **CareCast 아이콘**으로 열고, 개발 저장소 설치는 시설 PC에서 `http://localhost:3001` 을 여십시오.

> **주소가 `localhost` 여야 합니다.** 시설 PC에서 열더라도 랜 주소(`192.168.0.8:3001`)로
> 연 창은 **화면만 그리고 소리를 안 냅니다** — 시스템이 「다른 기기」로 보기 때문입니다.
> 2026-09-15 에 실제로 그랬습니다. 바탕화면에 「홈 화면에 추가」로 만든 아이콘이
> 랜 주소였고, 그것으로 연 창이 소리를 못 내고 있었습니다.
> **설치본은 바탕화면의 「CareCast 아이콘」, 개발 저장소 설치는 「CareCast 시작.bat」 으로 띄우십시오.**

**② `localSoundReady` 가 0입니까** — 창은 있는데 **소리가 잠긴 것**입니다.
`localClientsAlive` 는 1인데 이 값만 0이면 그 상태입니다.
**여는 것으로는 안 낫습니다** — 그 창에서 **F5** 를 누르거나 화면 위의
**「눌러서 소리 켜기」 띠**를 한 번 누르십시오.

> 브라우저가 자동재생을 막으면 창은 멀쩡히 그려지고 **소리만 안 납니다. 오류도 안 납니다.**
> 2026-09-15 아침 방송이 그렇게 지나갔고 이력에는 성공으로 남았습니다.
> 지금은 이 상태로 나간 방송을 **성공으로 안 적고 배너를 띄웁니다.**

**③ `localClients` 와 `localClientsAlive` 숫자가 다릅니까**
창은 있는데 **옛날 코드를 든 유령 창**입니다. 그 창에서 **F5**를 누르십시오.
그대로 두면 멀쩡히 나가는 방송이 이력에 실패로 찍히고 무음 경보가 뜹니다.

**④ 「전체 소리」가 0입니까** — §5를 보십시오.

**⑤ 출력 장치가 바뀌었습니까**
관리자 화면 오디오 쪽에서 스피커 이름을 확인하십시오. 다른 앱이 기본 장치를 바꿔 놓으면
방송이 엉뚱한 곳으로 나갑니다. 현장 PC는 2분마다 스스로 되돌립니다.

**⑥ 이 PC의 다른 앱 소리도 같은 스피커로 나갑니다.**
유튜브를 틀어 두신 채 잊으시면 그대로 전관에 나갑니다.

> **①~③을 확인하시기 전에는 「고장났다」로 결론 내리지 마십시오.**
> 이 시스템에서 가장 비싼 오판이 무음의 원인을 잘못 짚는 것입니다.

## 9-1. PC 시계 — **여기서 방송이 통째로 사라질 수 있습니다**

**방송은 「그 분이 되었을 때」 나갑니다.** 몇 분 늦게라도 내보내는 장치가 **일부러
없습니다** — 식사 전 안내가 10분 늦게 나가면 그건 안 나간 것보다 나쁘기 때문입니다.

**그래서 시계가 건너뛰면 그 사이 방송이 사라집니다.**

> **2026-09-15 에 실제로 일어났습니다.** 현장 PC 시계가 실제보다 2분 늦어 있었고
> (11:12 ↔ 11:14), 시간을 자동 동기화하자 **11:12 에서 11:16 으로 뛰었습니다.**
> 11:15 점심 식사 전 방송은 그 사이에 있었고, 시스템은 **11:15 를 한 번도 본 적이
> 없어서** 그냥 지나갔습니다. 화면도 아무 말이 없었습니다.

**지금은 조용히 지나가지 않습니다.** 시계가 뛰면 그 사이에 안 나간 방송이 있었는지
보고 **배너로 알립니다.** 그때는 「오늘 일과방송」에서 **▶** 로 직접 내보내시면 됩니다.

**그러니 시계는 이렇게 다뤄 주십시오.**

| | |
|---|---|
| **평소** | 윈도우 시간 자동 동기화를 **켜 두십시오.** 조금씩 어긋나는 것이 한꺼번에 뛰는 것보다 훨씬 낫습니다 |
| **시간을 손으로 맞추실 때** | **방송 시각 근처를 피하십시오.** 앞뒤 10분 안에서 맞추면 그 방송이 건너뛰어질 수 있습니다 |
| **이미 뛰었으면** | 배너를 보시고 **▶** 로 직접 내보내십시오 |

## 10. 업데이트

**자동 업데이트는 기본으로 꺼져 있습니다.** `server/.env` 에 `AUTO_UPDATE_ENABLED=1` 을 넣고 재시작하면 켜지고,
`AUTO_UPDATE_ENABLED=0` 으로 바꾸고 재시작하면 꺼집니다(README 「업데이트」).
켜 두면 **저장소로 설치한 PC(main 브랜치)만** 10분마다 확인하고, 새 것이 있으면 받아서
**방송 중이 아닐 때** 프로그램을 재시작합니다. 개발용 PC에서는 이게 돌지 않습니다.

**설치본(exe)은 스스로 받지 않습니다.** 설치 파일 안에 저장소 정보가 없기 때문입니다. 새 설치 파일을 받아 다시 설치하시고, 설치 중 **「기록을 그대로 두고 설치」**를 고르면 예약·이력·설정이 그대로 남습니다.

**업데이트 중에는 화면이 「업데이트 중입니다」로 바뀝니다.** 새 화면을 만드는 1~3분 동안
그렇고, **끝나면 스스로 돌아옵니다.** 그 창을 닫지 마십시오. 방송은 그동안에도 나갑니다.

- 화면은 대개 **스스로 새로고침**합니다.
- 그래도 **업데이트 직후에는 `/api/health` 를 한 번 보십시오**(§9의 ②).
  자동 새로고침에 실패하는 길이 둘 있어서, 확인 한 번이 3초입니다.
- 화면이 옛날 그대로면 **F5** 입니다.

## 11. 백업

**자동으로 됩니다** — 프로그램이 켜질 때 한 번, 그리고 매일 04:30.
`server\db\backups\` 에 30일치 남습니다.

**사람이 하셔야 하는 것은 하나입니다** — **한 달에 한 번, USB로 옮겨 두십시오.**
자동 백업은 **같은 디스크 안에** 있어서, 디스크가 죽으면 백업도 같이 죽습니다.

복구 절차는 [BACKUP.md](BACKUP.md)에 있습니다.

## 13. 이 시스템이 관리자께도 못 해 드리는 것

솔직하게 적습니다.

- **소리가 실제로 났는지 100% 알지 못합니다.** 나갔다는 기록까지입니다.
- **누가 들었는지는 모릅니다.**
- **인터넷이 끊기면 날씨·미세먼지·AI 문안과 (켠 경우) Azure 음성이 빠집니다.**
  **안내 음성(기본 엔진)과 음원 방송(안내 녹음·체조)은 그대로 나갑니다** — 목소리도 파일도 PC 안에서 만들고 꺼내서입니다.
- **정전이 되면 PC를 켜 줄 방법이 없습니다.** 프로그램으로는 못 하는 일입니다.
  BIOS의 「전원 복구 시 켜기」를 쓰시거나, 사람이 켜셔야 합니다.
- **스마트플러그 기능은 만들다 말았습니다.** 화면에 버튼은 있지만 연결된 장치가 없습니다.
